# Центр контролю EasyWAR (v4)

Локальний вебзастосунок для інтуїтивного контролю репозиторію **`hellwikcoop-arch/EasyWAR`** (а також `easywar-staff` і `easywar-releases`): живий огляд запитів на злиття (PR), збірок GitHub Actions, комітів, гілок, релізів, скріншотів, чеклістів приймання та чернеток доручень агентам.

Працює повністю **локально (local-first)**, без зовнішніх залежностей, у режимі **лише читання GitHub** — жодна дія не змінює репозиторії, не зливає PR і не надсилає оперативні дані в хмару.

## 5 розділів інтерфейсу

1. **Пульс** — оперативний екран «що потребує уваги зараз»: помилки або активні збірки CI, відкриті PR (готові й чернетки), прогрес чеклістів приймання, останній реліз, фокус поточного циклу та кнопка миттєвого оновлення **«Оновити»**.
2. **Код і релізи** — об’єднаний перегляд:
   - **PR** (із diff-статистикою `+ / - / файли`, SHA, перевірками Actions українською та бічною панеллю деталей);
   - **Збірки CI** (включно з теговими збірками `Desktop build`);
   - **Коміти** основної гілки;
   - **Гілки** репозиторію;
   - **Релізи** з переліком артефактів і їхніх розмірів.
3. **Екрани й збірки** — галерея скріншотів із GitHub Actions (`easywar-screens-*`), **локальне завантаження власних скріншотів** (PNG/JPEG/WebP, drag-and-drop, збереження в IndexedDB) та опорний набір екранів EasyWAR із повноекранним переглядом.
4. **Приймання й задачі** — інтерактивні чеклісти, завдання, рішення, відкриті питання та наступні кроки в одному місці зі створенням, редагуванням, прив’язкою до PR і видаленням.
5. **Агенти й журнал** — чернетки доручень агентам (SQLite, редагування, видалення, копіювання структурованого промпта з правилами безпеки `AGENTS.md`), контроль бюджетів/лімітів та журнал оновлень за київським часом (`Europe/Kyiv`).

## Швидкий запуск на Mac

### Варіант 1 — Фоновий сервіс (LaunchAgent, рекомендовано)
```bash
git clone https://github.com/hellwikcoop-arch/easywar-control.git
cd easywar-control
bash install.sh
```
Після встановлення відкрийте: **`http://127.0.0.1:8787`**  
Перевірка стану сервера: **`http://127.0.0.1:8787/health`**

- Порт **8787** не перетинається з мінісервером EasyWAR (**8766**).
- Файли копіюються в `~/Library/Application Support/EasyWAR Control`, а повторний запуск `bash install.sh` зберігає базу даних `state/center.sqlite3`.
- Зупинити й прибрати сервіс (зі збереженням бази): `bash uninstall.sh`.

### Варіант 2 — Прямий запуск без інсталяції (macOS / Linux)
```bash
python3 server.py
```

## Підключення токена читання GitHub (опційно)

Для публічних репозиторіїв центр працює одразу (ліміт 60 запитів/год). Щоб отримати підвищений ліміт (5 000 запитів/год) та завантаження артефактів скріншотів із GitHub Actions, сервер автоматично шукає токен лише для читання у такому порядку (перезапуск не потрібен):
1. Змінна середовища `EASYWAR_GITHUB_TOKEN`.
2. **Keychain Access** на macOS: generic password із `service = easywar-control-github` та `account = <ім’я користувача macOS>`.
3. Локальний `gh auth token`, якщо на Mac авторизований GitHub CLI (можна вимкнути через `EASYWAR_DISABLE_GH_CLI=1`).

Мінімально достатні права токена: **Metadata (read)**, **Contents (read)**, **Pull requests (read)**, **Actions (read)**. Ніколи не зберігайте токени в файлах репозиторію або `plist`.

## Резервне копіювання й доступ із телефона

- **Резервна копія SQLite:** `bash backup.sh` створює файл із правами `0600` у `~/Documents/EasyWAR-Control-Backups`.
- **Експорт/імпорт JSON:** доступний напряму в нижній частині бічного меню («Бекап» / «Імпорт»).
- **Доступ із iPhone:** сервер слухає виключно `127.0.0.1`. Для безпечного приватного доступу з телефона використовуйте **Tailscale Serve** у межах власного tailnet (не відкривайте порт публічно й не використовуйте Tailscale Funnel).
